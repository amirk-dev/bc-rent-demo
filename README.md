# Демонстрация системы управления арендой бизнес-центра

Открывается по ссылке, работает на компьютере и на телефоне, сервер не нужен.

**Все данные вымышлены.** Названия компаний, договоры, телефоны и суммы
не относятся к реальным организациям. Это демонстрация интерфейса:
кнопки нажимаются и состояние меняется, но ничего никуда не отправляется.

Разделы: шахматка помещений, карточка арендатора, начисления и счета,
напоминания об оплате, реестр договоров, аудит договоров, витрина
свободных площадей, сводка собственнику.

Без сборки и без внешних зависимостей: четыре файла, открываются как есть.
